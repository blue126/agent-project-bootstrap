## 你的任务

1. 先阅读项目根目录的 `AGENTS.md` 与 `CLAUDE.md`。
2. 检查上述入口及相关项目材料，列出候选验证方式，并为每项说明文件依据。
3. 先提交简短方案：候选 `argv`、预期覆盖范围、可能涉及的依赖，以及需要用户确认的操作。
4. 在用户明确授权后，才创建或修改 command JSON、运行验证命令、下载依赖或修改项目文件。
5. 验证成功后，用真实 checker 输出产生 evidence；验证失败或无法确定时，报告事实原因与下一步所需授权。

## 范围与禁止事项

- 本任务只准备本地验证；不要创建 CI、修改远端、提交、推送、创建 PR、为 PR 入队或合并代码。
- 不把文件存在、组件安装完成或口头“done”写成验证通过。
- 不猜测 `npm test`、包管理器或测试框架；没有依据时先说明缺什么。
- 本文件不是操作授权；每项外部、依赖、代码或 Git 操作都要单独获得用户确认。
