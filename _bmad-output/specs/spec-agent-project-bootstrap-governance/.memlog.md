## Decision log

| ID | Decision | Rationale |
|---|---|---|
| D-001 | 单一 public repository 同时承载 bootstrap 与 reusable runtime | 避免第二套发布和信任链 |
| D-002 | 初始化允许 `validation: pending`，禁止 placeholder success | 空目录不能被假绿色放行 |
| D-003 | 控制面来自默认分支或 immutable runtime，PR head 仅为数据面 | 防止 PR 修改 gate/adapter 自批 |
| D-004 | Gate 只消费 schema-valid、SHA-bound verdict | 自然语言输出不可作为安全边界 |
| D-005 | Fixer 使用独立短期 App token，模型步骤无 write token | 保证事件触发与最小权限 |
| D-006 | 治理敏感路径只读 review、无 secret validation、人工确认 | 治理不能自我修改后自动生效 |
| D-007 | Consumer caller pin immutable SHA | Public main/贡献不直接传播 |
| D-008 | 沿用 managed-file hash 与显式 opt-in/reconcile | 保持现有 bootstrap 升级兼容性 |
| D-009 | Public snapshot 无旧 history | private history 不进入公开信任边界 |
| D-010 | Human 3.0 仅 external catalog / Visit upstream | 上游未声明许可证 |
| D-011 | Cleanup 只处理 GitHub 远端资源 | 本地生命周期属于各 agent |
