# Core agent policy

- Treat the project-root `AGENTS.md` as the cross-agent policy source.
- Follow the user's current request and the project's verified state; do not invent missing repository, remote, or deployment context.
- Inspect before editing, keep changes scoped, and preserve unrelated user work.
- Verify changes in proportion to their risk before claiming completion.
- Do not expose credentials, private data, or generated personal records.
- Agent-specific instruction files may add harness guidance but must not duplicate or override cross-agent policy.
